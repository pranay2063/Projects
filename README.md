# Projects

A collection of research, programming, and computer science projects by [Pranay Ranjan](https://github.com/pranay2063).

## Projects

| Project | Description | Contents |
| --- | --- | --- |
| [Algorithms](Algorithms/) | Data structures, algorithms, and interview practice. | C++ and Java examples organized by topic, plus online judge solutions. [Original repository](https://github.com/pranay2063/Algorithms) |
| [CS17](CS17/) | Foundational computer science notes and examples. | Java, C++, object oriented programming, operating systems, and database concepts. [Original repository](https://github.com/pranay2063/CS17) |
| [LLD](LLD/) | Low level design exercises. | Java examples for caching, logging, producer-consumer, publish-subscribe, and rate limiting. [Original repository](https://github.com/pranay2063/LLD) |
| [Ensemble Pruning of ELMs with PSO](VELM_PSO/) | Research project on pruning ensembles of extreme learning machines using particle swarm optimization. | [Project notes](VELM_PSO/README.md) · [PDF report](VELM_PSO/Ensemble_Pruning_PSO.pdf) |

## Repository layout

Each project is kept in its own folder. The imported folders preserve the source repositories' internal paths and README files. See [SOURCES.md](SOURCES.md) for the source branches and commit snapshots.

These projects do not share a single build or test command. Follow the instructions in each project folder where available.
